# 화면정의서

작성일: 2026-09-27  
참조: `docs/PLAN.md`, `DESIGN.md`

## 공통 원칙

- 공개 글과 작성 본문의 가로 폭·글꼴·문단 간격을 동일하게 쓴다.
- 화면 폭 768px 미만에서는 사이드바를 접고, 미리보기는 전환형 패널로 바꾼다.
- 모든 사진에는 대체 텍스트 입력 경로가 있다.

## S-01. 홈 `/`

| 영역 | 구성 | 동작 |
| --- | --- | --- |
| 헤더 | 사이트명, 메뉴 트리, 검색, 스튜디오 | 하위 메뉴는 클릭 또는 키보드로 열림 |
| 소개 | 짧은 자기소개와 최근 기록 수 | 과장된 히어로 이미지는 사용하지 않음 |
| 최근 기록 | 카테고리·날짜·제목·요약 | 글 상세로 이동 |
| 기록 지도 | 다섯 메뉴의 한 줄 설명 | 해당 아카이브로 이동 |

## S-02. 아카이브 `/:section`

| 영역 | 구성 | 동작 |
| --- | --- | --- |
| 제목부 | 메뉴명, 설명, 글 수 | 하위 메뉴가 있으면 칩으로 노출 |
| 필터 | 태그, 연도, 정렬 | URL 쿼리와 동기화 |
| 목록 | 제목, 요약, 날짜, 썸네일(선택) | 일상은 사진 비중을 높임 |

## S-03. 글 상세 `/:section/:slug`

| 영역 | 구성 | 동작 |
| --- | --- | --- |
| 글 머리 | 경로, 제목, 요약, 날짜, 태그 | 구조화 데이터와 OG 원본 |
| 본문 | 720px 폭의 서식·이미지·캡션 | 이미지 클릭 시 전체 보기 |
| 끝맺음 | 이전/다음 글, 관련 태그 | 독자의 다음 읽기를 지원 |

## S-04. 스튜디오 대시보드 `/studio`

| 영역 | 구성 | 동작 |
| --- | --- | --- |
| 좌측 | 모든 글, 임시저장, 발행됨, 메뉴 | 현재 항목 강조 |
| 중앙 | 최근 초안과 `새 글` | 글 클릭 시 작성 화면 |
| 상단 | 저장 상태, 미리보기, 발행 | 자동저장 후 상태 표시 |

## S-05. 작성 화면 `/studio/posts/:id`

| 영역 | 구성 | 동작 |
| --- | --- | --- |
| 상단 바 | 뒤로, 저장 상태, 미리보기, 발행 | 항상 보이되 화면을 차지하지 않음 |
| 메타 패널 | 카테고리, 태그, 요약, 대표 이미지, 공개 상태 | 데스크톱 우측, 모바일 접힘 패널 |
| 편집 캔버스 | 제목, 본문, 블록 삽입 | 클릭 즉시 작성. Enter/Shift+Enter 구분 |
| 서식 막대 | 되돌리기, 스타일, 글꼴, 크기, 꾸밈, 정렬, 링크, 사진 | 선택 영역이 없으면 비활성인 항목 최소화 |
| 슬래시 메뉴 | 사진, 제목, 인용, 목록, 구분선 | `/` 입력 시 키보드로 선택 |
| 이미지 맥락 막대 | 작게, 본문, 와이드, 직접 폭, 정렬, 대체 텍스트, 캡션, 삭제 | 이미지를 선택했을 때만 표시 |
| 미리보기 | 데스크톱/모바일 실제 글 화면 | 작성 화면과 동일한 렌더러 사용 |

## S-06. 메뉴 편집 `/studio/navigation`

| 영역 | 구성 | 동작 |
| --- | --- | --- |
| 트리 목록 | 드래그 손잡이, 이름, 경로, 공개 스위치 | 드래그 정렬과 계층 변경 |
| 인라인 편집 | 이름·URL | Enter 저장, Escape 취소 |
| 동작 | 추가, 삭제, 들여쓰기, 내어쓰기 | 변경 후 미리보기 메뉴 즉시 반영 |

## 반응형 정의

- Desktop 1024px 이상: 3열(탐색·캔버스·메타) 또는 2열(캔버스·미리보기).
- Tablet 768–1023px: 탐색 패널 접기, 캔버스+메타 2열.
- Mobile 767px 이하: 한 열, 메타와 미리보기는 하단 시트/탭, 서식 막대는 가로 스크롤.
